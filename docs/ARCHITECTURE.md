\# Architecture



Radium SDK is developed as a deeply integrated toolkit with distinct components.



\## Engine Patches



Contains patches and build instruction for Meta's UE4.27.1 development build.
Streamlines making custom materials, loading custom maps and many more neat and
nifty things SIGNIFICANTLY. 

## Runtime



A fork of UE4SS with mod loading, scripting, hooks, and runtime diagnostics built
for deeper integration in ITR1. 



\## Compatibility Layer



Integrations (executable detection, function discovery, layouts, and adapters for
supported ITR1 builds).

## Public API

Documented functions and events for mod developers to use in their projects. API 

will use the compatibility layer.



\## Editor and Tools

Project creation, file validation, cooking, packaging, deployments and diagnostics.
CLI operations should be reusable
