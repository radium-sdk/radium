\# Radium SDK



\*\*Radium\*\* is a comprehensive \*\*Modding Framework\*\* built for Into the Radius 2.7 which aims to \*\*streamline\*\* every aspect of the development process, from compiling all the way to your final build. 



\## Features



\* \*\*Radium-UE4SS\*\* - A fork of UE4SS for Radium which bring loader/runtime changes, and reusable fixes contributed upstream

\* \*\*ITR Compatibility Layer\*\* - Executable signatures, game-specific hooks, startup behavior and more

\* \*\*Radium API\*\* - Stable interfaces that any mod author can use in their project, avoiding addresses

\* \*\*UE4 Engine Patches\*\* - Patches for Meta's UE4.27.1 (materials, landscaping tools, building, etc.)
